# Quantum-dot single-photon source

Cinematic 34-second schematic of a quantum-dot micropillar single-photon source, with a synthetic Hanbury Brown–Twiss histogram.

Scientific schematic with idealized preparation and synthetic detection. Representative device—not a fabrication design.

The built site is on the `pages` branch: https://github.com/mizcausevic-dev/qd-single-photon-explainer/tree/pages

GitHub Pages is not serving it yet. The connected GitHub app can push the repository and cannot change Pages settings (`403 Resource not accessible by integration`). In the repository settings, choose Deploy from branch `pages` and folder `/`. The site is then https://mizcausevic-dev.github.io/qd-single-photon-explainer/

Source, tests, and the Medium draft (`MEDIUM.md`) are on `main`.

```bash
npm install
npm test
npm run dev
```
